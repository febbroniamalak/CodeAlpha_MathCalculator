# CodeAlpha_MathCalculator
# 🧮 Calculator Website

A simple and responsive **Calculator Web App** built using **HTML**, **CSS**, and **JavaScript**.  
It performs basic arithmetic operations like addition, subtraction, multiplication, and division — all inside a clean and modern interface.

## 💡 Features
- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🧼 Clear button to reset the display  
- 💻 Responsive layout that works on mobile and desktop  

## 🧱 Technologies Used
- **HTML5** – Page structure  
- **CSS3** – Styling and button layout  
- **JavaScript** – Calculation logic and event handling  

## ✨ Future Improvements
- Add keyboard input support  
- Add scientific calculator mode  
- Improve design with animations
